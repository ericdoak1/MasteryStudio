# Mastery Messaging Agent

Mastery conversations across Linq iMessage and Twilio phone calls.

## Emma voice notes

Linq replies support three delivery modes through `LINQ_REPLY_MODE`:

- `text`: always send a written reply
- `voice`: use Emma's ElevenLabs voice when the reply is short enough
- `auto`: let Emma use voice selectively for welcomes, reflections, insights, and check-ins

Voice replies are generated by ElevenLabs, pre-uploaded to Linq, and sent through
Linq V3's voice-memo endpoint. They render as native voice bubbles on iMessage and
as audio attachments on RCS/SMS. If synthesis fails or the provider definitively
rejects the voice send, the same reply is sent as text. Incoming audio messages are
transcribed and continued in the same conversation.

## Command Center send endpoint

`POST /linq/send` uses `Authorization: Bearer $OUTBOUND_API_KEY`.

Send to an existing conversation:

```json
{
  "chatId": "linq-chat-uuid",
  "text": "I kept thinking about what you said earlier...",
  "delivery": "voice",
  "idempotencyKey": "cc-send-018f6f2e"
}
```

Start a new conversation with a text introduction followed by a native voice note:

```json
{
  "to": "+15551234567",
  "introText": "Hi, it's Emma from Mastery.",
  "text": "I would love to get to know you and how you coach.",
  "delivery": "voice",
  "idempotencyKey": "cc-send-018f6f2f"
}
```

For `delivery: "auto"`, pass `purpose` as `welcome`, `reflection`, `insight`,
`check_in`, `question`, or `logistics`. The first four prefer voice. Text is the
safe default.

Generate `idempotencyKey` once for each Command Center send action and reuse it
for retries. Voice notes are restricted to verified one-to-one chats. When a phone
number matches more than one direct Linq chat, send the intended `chatId` instead
of letting the service guess. A true first contact receives Emma's identification
text before the voice note; an existing direct thread does not repeat it.
The response includes `service`, `delivery`, `fellBackToText`, and
`nativeVoiceBubble` so the Command Center can show what was actually delivered.

ElevenLabs request logging is explicit through `ELEVENLABS_ENABLE_LOGGING`.
Accounts entitled to ElevenLabs zero-retention mode can set it to `false`.

Native voice-memo sends do not have provider-level idempotency. This service
deduplicates Command Center operations for 24 hours in the running process and
requires a caller idempotency key. Before running multiple instances, move that
operation record and inbound webhook processing into the shared durable data layer.
For sensitive coaching audio, enable Linq's ephemeral attachment tier for the
Mastery number and confirm the ElevenLabs retention setting for the account.

See `.env.example` for configuration. Keep API keys in Render or another secret
manager, never in the repository.
