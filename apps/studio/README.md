# Mastery Studio

This directory is the only production home for the Mastery Studio web product.

Studio is for leaders, coaches, teams, experts, and organizations.

## Product promise

Turn what a leader or organization believes into a clear, repeatable system for developing people, building strong teams, and improving performance.

## First production surface

The first version should stay small:

- Home / Emma
- Vision + Mission
- Weekly Theme
- People
- Knowledge
- Tools
- Programs

Everything reads and writes through the shared Core Platform. No local-only Studio state.

## Emma rule

Emma must have permission-scoped access to the same data visible in Studio and must be able to write approved changes back to it.
