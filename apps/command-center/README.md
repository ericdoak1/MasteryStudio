# Mastery Command Center

This directory is the only production home for the internal Mastery Command Center.

Command Center is for Mastery operators, not customers.

## First production surface

- Organizations
- People
- Agents
- Activity
- Knowledge
- Integrations
- System

## Core workflow

Create organization → add people → choose/create agent → give task → send by text or call → conversation → transcript → knowledge extraction → review → publish into Studio/Mastery.

## Rule

Command Center operates the shared Core Platform. It must never create a separate person record, knowledge store, agent memory, or messaging history from Studio/Mastery.
